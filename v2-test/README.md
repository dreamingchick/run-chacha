# 챠챠 v2 내부 테스트 빌드

이 폴더는 내부 확인용 정적 게임입니다. GitHub Pages에 자동 배포되지 않습니다.

## 로컬에서 실행

PowerShell에서 이 폴더로 이동한 뒤 실행하세요.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 열면 됩니다. Python 명령이 없으면 `py -m http.server 8000`을 사용하세요.

테스트 화면의 `v2 플레이 테스트`에서 장애물 종류, 시작 배속, 무적 모드, 충돌 범위 표시를 선택할 수 있습니다. 실행 조작은 Space 또는 위쪽 화살표이며, 공중에서 다시 누르면 이중 점프합니다.

이 빌드는 `test` 브랜치에만 보관되며 `main` 병합이나 Pages 배포는 하지 않았습니다.
